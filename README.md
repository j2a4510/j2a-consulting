# J2A Consulting – site web

Site vitrine de J2A Consulting SARL (Lomé, Togo), en français et en anglais.

- Les textes et la carte des corridors sont dans `build.py`.
- Après une modification : `python3 build.py`, puis publier.
- Styles : `assets/style.css`. Logo : `assets/logo.svg`.
- Hébergement : GitHub Pages, branche `main`, dossier racine.
